# Nova Landing Page 🚀

თანამედროვე, სრულად ადაპტირებადი (Responsive) და სემანტიკური Landing Page შექმნილი სუფთა HTML5-ით, თანამედროვე CSS3-ითა და Vanilla JavaScript-ით გამოცდილი დეველოპერის სტანდარტების დაცვით.

---

## 📁 პროექტის სტრუქტურა

```text
├── index.html       # სემანტიკური HTML5 სტრუქტურა (Hero, About, Features, Contact, Footer)
├── style.css        # თანამედროვე CSS3 (Variables, Flexbox/Grid, Dark/Light თემა, ანიმაციები)
├── script.js        # Vanilla JS (მოდულარული არქიტექტურა, ვალიდაცია, თემების გადართვა, Toast)
└── README.md        # პროექტის დოკუმენტაცია
```

---

## ✨ ძირითადი ფუნქციონალი

1. **სემანტიკური HTML5 & Accessibility (a11y)**:
   - გამოყენებულია `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` ტეგები.
   - სრული ARIA ატრიბუტები (`aria-label`, `aria-expanded`, `aria-describedby`, `aria-live`).

2. **თანამედროვე CSS3**:
   - **CSS Custom Properties (Variables)** ფერების, ჩრდილებისა და შრიფტების მართვისთვის.
   - **მუქი / ღია თემა (Dark / Light Mode)** მომხმარებლის არჩევანის LocalStorage-ში შენახვითა და სისტემური (OS) თემის ამოცნობით.
   - **Glassmorphism & Gradients** ვიზუალური აქცენტებისთვის.
   - სრული ადაპტირება მობილურ, ტაბლეტ და დესკტოპ ეკრანებზე (`clamp()`, CSS Grid, Flexbox).

3. **ინტერაქტიული JavaScript (ES6+)**:
   - **ფორმა და JS ვალიდაცია**: რეალურ დროში შემოწმება (`input` / `blur`), სიმბოლოების მრიცხველი, ელ-ფოსტის Regex ვალიდაცია, სავალდებულო ველების გაფრთხილებები და წარმატების ინდიკატორი.
   - **ასინქრონული გაგზავნის სიმულაცია**: Loading სპინერი და ღილაკის დაბლოკვა დუბლირების თავიდან ასაცილებლად.
   - **ScrollSpy**: აქტიური ნავიგაციის ბმულის ავტომატური მონიშვნა `IntersectionObserver`-ის მეშვეობით.
   - **მობილური მენიუ**: გლუვი ანიმაცია, კლავიატურის მხარდაჭერა (`Escape`) და გარე კლიკზე დახურვა.
   - **Toast შეტყობინებების სისტემა**: მყისიერი ვიზუალური უკუკავშირი მომხმარებლისთვის.

## 🚀 როგორ გავუშვათ პროექტი

პროექტს არ სჭირდება დამატებითი ბიბლიოთეკები ან Node.js პაკეტები (Zero-dependency):

1. გახსენით ფაილი `index.html` პირდაპირ ნებისმიერ ბრაუზერში (Chrome, Firefox, Safari, Edge).
2. ან გამოიყენეთ VS Code-ის გაფართოება **Live Server** ლოკალური სერვერის გასაშვებად.
